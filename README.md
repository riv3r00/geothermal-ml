# Geothermal ML

Exploring the use of machine learning for geothermal resource
exploration and subsurface characterization.

## Initial Research Question

Can machine learning use publicly available geoscience data to
identify areas of high geothermal potential?

## Long-Term Research Question

How well do machine-learning models trained on one geothermal
region generalize to geologically different regions?

## Project Roadmap

1. Collect and explore public geothermal datasets
2. Visualize geothermal measurements geographically
3. Build baseline machine-learning models
4. Incorporate additional geological and geophysical features
5. Test model generalization across geographic regions
6. Explore physics-informed machine learning
